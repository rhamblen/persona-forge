LoRA

Dataset staged —

Staging uploads your selected images into ComfyUI's input folder so the trainer can read them. Auto-captioning and the training run arrive in 0.5.1 / 0.5.2.

Train

Each image is auto-captioned with Florence-2 and prefixed with your trigger word, then the LoRA trains on the captioned set. Training frees VRAM first (unloads the Ollama model + ComfyUI's models) and runs on the GPU — a real run of a few hundred steps takes a while. The LoRA appears under “Trained LoRAs” when it finishes; lower the steps for a quick test.
